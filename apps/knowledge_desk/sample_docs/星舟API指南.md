# 星舟API指南（演示资料）
这份指南描述虚构的星舟平台API规则，可作为问答与检索评测材料。

## 身份认证与密钥轮换
星舟API使用Authorization: Bearer请求头认证，不接受URL查询参数中的密钥。API密钥每90天轮换一次；旧密钥与新密钥可并存24小时，之后撤销旧密钥。不要将密钥记录到工单或日志。

## 请求限流
每个星舟工作空间每分钟最多60次请求，最多4个并发任务。超过限额返回HTTP 429，客户端应读取Retry-After响应头，等待指定秒数后重试。不要通过创建新工作空间绕过限流。

## 幂等请求
创建星舟工单时必须提供request_id，服务在24小时内保留幂等结果。相同request_id与相同内容返回原工单编号，不重复创建；相同request_id对应不同内容返回HTTP 409。并发请求通过数据库唯一约束避免重复写入。

## 错误码处理
星舟HTTP 401表示密钥无效，HTTP 403表示缺少权限，HTTP 404表示资源不存在，HTTP 409表示状态冲突，HTTP 429表示限流。HTTP 503表示服务暂时不可用，可以指数退避重试，最多3次。401和403不应自动重试。

## 文件上传限制
星舟知识库支持UTF-8编码的TXT、Markdown和含文字层的PDF。每个文件最多5MB，PDF最多100页。扫描PDF需要先进行OCR。相同内容重复上传直接返回已有文档编号，不重复切分。

## 会话与权限
星舟每个会话使用独立thread_id保存状态。用户只能访问自己的会话、文档和工单。两个请求同时修改同一会话时，后一个请求返回HTTP 409；不同会话可以并行执行。

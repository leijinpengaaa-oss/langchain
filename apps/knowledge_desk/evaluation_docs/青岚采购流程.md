# 青岚采购流程（虚构评测资料）

这是为知识问答质量评测新编写的虚构业务资料，不是企业真实流程。所有规则仅用于本项目的测试。文档没有提供任何实际密码、个人姓名、联系方式或合同赔偿金额。

## 采购审批金额
单笔采购金额不超过8000元，由部门经理审批；超过8000元且低于50000元，由财务负责人审批；达到或超过50000元，还须业务负责人联合审批。金额按含税总价计算，不允许通过拆分采购绕过审批。

## 供应商准入资料
新供应商需要提交营业执照、对公银行账户信息和合规声明。供应商准入审核结果有效期为180天，超过有效期必须重新审核。此文档不包含供应商登录密码或任何真实银行账号。

## 报价与下单
单笔采购含税总价达到15000元时，必须收集至少3家供应商的正式报价。采购订单草稿保留2个工作日；期间未完成审批则自动失效，需要重新发起。正式下单前必须完成对应金额的审批。

## 收货与验收
货物到达后7个自然日内完成验收，检查数量、外观和订单规格。发现数量不足或损坏时记录异常并通知采购专员，异常未处理前不能确认验收通过。验收记录至少保留18个月。

## 发票与付款
付款批次为每月10日和25日。合规发票、采购订单和验收记录三项齐全后，财务在3个工作日内完成审核，再安排最近付款批次。缺少任意一项时暂停付款。此资料没有规定逾期赔偿金额。

## 退货办理
需要退货时，收货人应在签收后10个自然日内提交退货申请，说明退货原因并附异常照片。采购专员审批通过后，在2个工作日内安排取件。供应商具体联系电话和取件人员姓名不在本文中。
